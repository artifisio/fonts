Use it

Link the stylesheet from jsDelivr
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/artifisio/fonts@main/sets/multi-sans/multi-sans.css" />
Then set the family
font-family: 'Multi Sans', sans-serif;
Or self-host: npx artifisio add writes these rules next to the files
@font-face { font-family: 'Multi Sans'; font-style: normal; font-weight: 400; font-display: swap; src: url('./multi-sans-regular.woff2') format('woff2'), url('./multi-sans-regular.otf') format('opentype'); }

Add --format woff2 to install only the web format.
