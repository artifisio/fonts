# Quill Text

**[Open in the gallery →](https://artifisio.github.io/fonts/quill-text/)**

A humanist old-style text serif for book pages — diagonal stress, bracketed serifs, calligraphic entries.

1 style · latin · OTF · WOFF2 · [OFL-1.1](https://openfontlicense.org)

## Install

```bash
npx artifisio add quill-text --kind font
```

Or link the stylesheet straight from jsDelivr:

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/artifisio/fonts@main/sets/quill-text/quill-text.css" />
<style>body { font-family: 'Quill Text', serif; }</style>
```

Styles: Regular (400).
