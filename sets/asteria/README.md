# Asteria

**[Open in the gallery →](https://artifisio.github.io/fonts/asteria/)**

A geometric sans built from circles and straight lines — single-storey a and g, pointed apexes, even monoline strokes.

1 style · latin · OTF · WOFF2 · [OFL-1.1](https://openfontlicense.org)

## Install

```bash
npx artifisio add asteria --kind font
```

Or link the stylesheet straight from jsDelivr:

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/artifisio/fonts@main/sets/asteria/asteria.css" />
<style>body { font-family: 'Asteria', sans-serif; }</style>
```

Styles: Regular (400).
