# Fieldbook

**[Open in the gallery →](https://artifisio.github.io/fonts/fieldbook/)**

A humanist sans for wayfinding and long interface text — broad-nib skeletons, open apertures, calm even colour.

<p>
<a href="https://artifisio.github.io/fonts/fieldbook/"><img src="specimen.svg" width="660" alt="Fieldbook" /></a>
</p>

2 styles · latin · OTF · WOFF2 · [OFL-1.1](https://openfontlicense.org)

## Install

```bash
npx artifisio add fieldbook --kind font
```

Or link the stylesheet straight from jsDelivr:

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/artifisio/fonts@main/sets/fieldbook/fieldbook.css" />
<style>body { font-family: 'Fieldbook', sans-serif; }</style>
```

Styles: Regular (400), Bold (700).
