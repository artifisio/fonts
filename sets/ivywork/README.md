# Ivywork

**[Open in the gallery →](https://artifisio.github.io/fonts/ivywork/)**

A botanical Art Nouveau display serif — vine-like stems, terminals curling into tendrils and single leaves.

1 style · latin · OTF · WOFF2 · [OFL-1.1](https://openfontlicense.org)

## Install

```bash
npx artifisio add ivywork --kind font
```

Or link the stylesheet straight from jsDelivr:

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/artifisio/fonts@main/sets/ivywork/ivywork.css" />
<style>body { font-family: 'Ivywork', sans-serif; }</style>
```

Styles: Regular (400).
