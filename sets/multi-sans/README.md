# Multi Sans

**[Open in the gallery →](https://artifisio.github.io/fonts/multi-sans/)**

A condensed grotesque sans with tall, even letterforms. Basic Latin letters and figures (A–Z, a–z, 0–9); punctuation is not covered yet.

<p>
<a href="https://artifisio.github.io/fonts/multi-sans/"><img src="specimen.svg" width="660" alt="Multi Sans" /></a>
</p>

1 style · latin · OTF · WOFF2 · [OFL-1.1](https://openfontlicense.org)

## Install

```bash
npx artifisio add multi-sans --kind font
```

Or link the stylesheet straight from jsDelivr:

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/artifisio/fonts@main/sets/multi-sans/multi-sans.css" />
<style>body { font-family: 'Multi Sans', sans-serif; }</style>
```

Styles: Regular (400).
