# Atrium Flare

**[Open in the gallery →](https://artifisio.github.io/fonts/atrium-flare/)**

A flared incised sans — stems swell into subtle concave flares instead of serifs, classical proportions.

2 styles · latin · OTF · WOFF2 · [OFL-1.1](https://openfontlicense.org)

## Install

```bash
npx artifisio add atrium-flare --kind font
```

Or link the stylesheet straight from jsDelivr:

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/artifisio/fonts@main/sets/atrium-flare/atrium-flare.css" />
<style>body { font-family: 'Atrium Flare', sans-serif; }</style>
```

Styles: Regular (400), Bold (700).
